## Điều khiển

| Phím / UI | Tác dụng |
|-----------|----------|
| `←` `→` / Space | Chuyển slide |
| Rail CP (header) | Nhảy tới checkpoint |
| Timer panel | Đồng hồ riêng từng CP — tự start khi vào slide CP |
| `P` | Pause / Resume timer |
| `R` | Reset timer về đủ phút CP |

Thời lượng: CP0 20′ · CP1 40′ · CP2 45′ · CP3 45′ · CP4 40′ · CP5 30′.
